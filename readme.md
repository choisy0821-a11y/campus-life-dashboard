# 🎓 캠퍼스 생활 설문조사 분석 웹앱

인문사회대 학생들의 설문조사 데이터를 기반으로 학과별 생활 습관 차이, 생활 습관과 학교생활 만족도 간의 관계, 그리고 학생들의 한줄의견 텍스트를 직관적으로 분석하고 시각화하는 Streamlit 웹 애플리케이션입니다.

---

## 📌 주요 기능

1. **데이터 업로드 및 결측치 점검**
   - CSV 파일 업로드 및 상위 5개 행 미리보기 제공
   - 열별 결측치(누락된 값) 개수 표시
   - 음수 값과 같은 비정상 수치 데이터 자동 탐지 및 경고 표시

2. **학과별 데이터 필터링**
   - 드롭다운 선택 상자를 통해 특정 학과 또는 전체 학생 데이터를 선택하여 필터링 분석

3. **생활 습관 및 만족도 시각화**
   - **학과별 평균 생활 습관 비교:** 학과별 공부시간, 수면시간, 스마트폰 사용시간을 묶음 막대그래프(Bar Chart)로 비교
   - **생활 습관과 만족도 관계 분석:** 
     - 공부시간 vs 만족도
     - 수면시간 vs 만족도
     - 스마트폰 사용시간 vs 만족도
     - 3개 항목 각각에 대한 산점도(Scatter Plot) 및 선형 추세선(OLS Trendline) 제공

4. **학생 한줄의견 텍스트 분석**
   - 2글자 이상의 빈출 키워드 상위 10개(Top 10) 막대그래프 시각화
   - 긍정 및 부정 감성 단어 빈도 카운트 및 감지된 단어 목록 나열
   - 긍정 vs 부정 단어 비율을 비교하는 원그래프(Pie Chart) 제공

---

## 📂 CSV 데이터 형식 안내

원활한 분석을 위해 업로드하는 CSV 파일에는 다음과 같은 컬럼명이 포함되어 있는 것을 권장합니다:

| 컬럼명 | 데이터 형태 | 설명 |
| :--- | :--- | :--- |
| `학과` | 문자열 (Text) | 학생 소속 학과명 |
| `공부시간` | 숫자 (Float/Int) | 일일 평균 공부 시간 |
| `수면시간` | 숫자 (Float/Int) | 일일 평균 수면 시간 |
| `스마트폰` | 숫자 (Float/Int) | 일일 스마트폰 사용 시간 (`스마트폰 사용시간`도 호환) |
| `만족도` | 숫자 (1~5점 등) | 학교생활 만족도 (`학교 생활 만족도`도 호환) |
| `한줄의견` | 문자열 (Text) | 학교생활에 대한 자유 의견 (`의견`도 호환) |

## 🚀 실행 방법

### 1. 패키지 설치
터미널(또는 명령 프롬프트)을 열고 프로젝트 폴더 경로에서 아래 명령어를 실행하여 필요한 라이브러리를 설치합니다:

```bash
pip install -r requirements.txt
```

### 2. 애플리케이션 실행
설치가 완료된 후 다음 명령어를 입력하여 웹앱을 구동합니다:

```bash
streamlit run app.py
```

명령어를 실행하면 로컬 웹 브라우저(`http://localhost:8501`)가 자동으로 열리며 분석 화면이 표시됩니다.
